MathsSimplify fully
Remember

Find the BIGGEST number that divides both the numerator and the denominator. ÷ both by it. Simplified fully means only 1 divides both.

Worked example

Simplify fully2440
Both divide by8
So2440÷8=÷835

2 and 4 divide both too, but 1220 and 610 are not simplified fully. 8 is the biggest number that divides 24 and 40. After ÷ 8, only 1 divides both 3 and 5.

Verbal reasoningMissing letters
Remember

One letter ends the first word and starts the second. The SAME letter must work in BOTH pairs, so check all four words.

Worked example

fou(r)ainsta(r)ed
The letter
strne

Check all four words: four, rain, star, red. They all work, so the letter is r. With t you get ‘fout’: not a word, so t is out.
