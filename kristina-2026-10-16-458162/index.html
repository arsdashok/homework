1

Ask someone how long something usually takes. Start with How long.

Like this: How long does it take you to make a cake?

2

Ask someone how long something took that one time. Start with How long.

Like this: How long did it take you to learn to swim?

3

What took you a long time this week? Start with It took me.

Like this: It took me forty minutes to find my car keys on Tuesday.
